# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.4.0   | 🔴 No     |

## Reporting a Vulnerability

For security vulnerabilities, email [greymon647@gmail.com](mailto:greymon647@gmail.com).

## Reporting Ordinary Bugs

For ordinary bugs, compiler errors, unexpected behavior, and feature requests, please [open a GitHub issue](https://github.com/marboris/razlang/issues). Include the Raz version and steps to reproduce the issue.

## Scope

This policy covers security issues related to Raz. The project is under active development and has not undergone a formal security audit.
