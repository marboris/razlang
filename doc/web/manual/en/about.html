About This Manual

About the Raz language and compiler manual, its organization, and its technical references.

Raz Gen2 Manual·About

Purpose

The Raz Manual records the language surface, expected compiler responsibilities, standard-library APIs, and platform/toolchain behavior. The intent is to make feature decisions explicit before expanding the implementation.

Documentation rules

  • Public manual pages are authored as static HTML and share a common stylesheet and navigation system.
  • Each feature should have a concise registry entry or index link and a dedicated page when detailed syntax or semantics matter.
  • Examples should reflect the actual implementation and avoid implying behavior that has not been specified.
  • Design references must state whether they are syntax, terminology, or conceptual inspiration.
  • The implementation snapshot and approved language contract must remain distinguishable.
