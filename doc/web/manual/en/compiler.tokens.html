Lexer Token Reference

Current token IDs from the active Raz lexer.

Raz Gen2 Manual·Compiler

This table exists to make the current lexer inspectable. Token IDs are private compiler implementation details until explicitly stabilized; source-language specifications should refer to spellings and semantic roles.

Special and literal tokens

Kind ID Details
End of file 0 Terminates the token stream.
Identifier 1 Also the fallback kind for unrecognized words that are not keywords.
Numeric literal 2 Integer or decimal spelling.
String literal 3 Double-quoted; selected escapes decoded during lexing.
Character literal 4 Single-quoted; currently stored as a numeric character code represented as text.
Unknown single character 99 Fallback from operator recognition; diagnostic policy needs specification.
