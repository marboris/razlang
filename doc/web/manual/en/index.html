How to read this manual

Feature pages distinguish the current implementation from decisions that still need approval. Design references record where a concept was inspired by another language; they do not imply identical syntax or semantics.

Use the search field above to find a keyword, operator, type, compiler stage, or standard module. Token numbers are documented as internal lexer identifiers rather than stable language-level names.
