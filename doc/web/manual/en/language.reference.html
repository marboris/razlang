Language Reference

Language Reference

A compact index of the constructs recognized by the current Raz Gen2 implementation.

Raz Gen2 Manual·Language ReferenceImplementation inventory
Scope: this reference is an inventory of observable implementation behavior. The normative grammar and several type and memory rules still require explicit approval.

Core syntax

Construct Example Purpose / status
Function function add(a: i64, b: i64) -> i64 { ... } Named function with parameter and return types. Implemented
Structure struct Point { x: i64; y: i64; } User-defined record with named fields. Implemented
Binding let count: i64 = 0; Mutable local or file-level binding. Type may be inferred. Implemented
Immutable binding const limit: i64 = 10; Binding reassignment is rejected. Nested and aliased mutation rules remain open. Partial
Conditional if (ready) { ... } else { ... } Conditional execution. Parentheses are currently optional in parser handling. Implemented
Loop while (ready) { ... } Conditional iteration. Implemented
Return return result; Returns from a function or top-level execution. Implemented
Source inclusion include "math.raz"; Compile-time source expansion. Contract review
Module / native import use std.io; Imports a Raz module; a quoted path selects a native header. Implemented
Macro define twice(x) { x + x } Token-aware source macro expansion. Partial

Open language decisions

  • Make semicolon and optional-parenthesis rules consistent and normative.
  • Define conversions, integer overflow, pointer safety, reference lifetime, and function-value semantics.
  • Resolve the inconsistent extern handling before documenting it as supported syntax.
